# 验证指南

不要把“LS-DYNA 能读入 K 文件”当作转换成功。推荐按以下顺序建立验证证据。

## 1. 结构检查

- 查看 `.conversion.json`，严格模式下必须为 0 个 `ERROR`；
- 对照 `.idmap.csv` 抽查实例、节点和单元；
- 在 LS-PrePost 中检查零体积、负体积、重复节点、法向和初始穿透；
- 比较 Abaqus 与 LS-DYNA 的总节点数、单元数、部件数和质量。

## 2. 单卡试验

每一种材料至少建立一个单单元模型，分别验证：

- 弹性斜率、屈服点、硬化曲线；
- 速率与温度响应；
- 损伤起始、软化和删除时刻；
- EOS 的压力—体积/冲击 Hugoniot 响应；
- 壳厚度、积分点和梁截面方向。

## 3. 子系统试验

- 用两块简单试件验证每一种接触、摩擦和绑定；
- 用单位载荷验证 SPC、位移、速度、力、压力和重力方向；
- 核对每个幅值在总时间/步时间下的曲线；
- 检查刚体参考点、约束力与力矩传递。

## 4. 整体模型

- 先用缩短终止时间运行，检查 `d3hsp` 和 `messag`；
- 监控动能、内能、小时玻璃能、接触能、滑移能和总能量误差；
- 检查最小时间步及控制单元、质量缩放增量；
- 与 Abaqus 对比关键位移、速度、反力、接触力、损伤变量和能量历史；
- 完成网格、时间步、接触刚度和侵蚀参数敏感性分析。

只有通过相应层级的对比，才能认为具体模型的转换具有工程等价性。
